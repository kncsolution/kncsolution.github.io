Executive Brief

Virtual Knowledge Graph — 데이터를 옮기지 않고 의미로 질의한다

tabularis에 추가되는 신규 레이어. 기존 관계형 DB를 그대로 둔 채, 비즈니스 의미(온톨로지) 기준으로 조회·검증하는 기능을 제공합니다.

왜 필요한가

데이터는 테이블에 흩어져 있지만, 업무는 "고객", "계약", "정산"처럼 의미 단위로 돌아갑니다. 지금까지는 이 둘을 잇기 위해 데이터를 복제하거나 별도 그래프 DB에 옮겨야 했습니다. VKG는 원본 DB를 손대지 않고 그 위에 "의미 계층"만 얹어, 실시간으로 최신 데이터를 의미 기준으로 조회·검증할 수 있게 합니다.

1

원본 데이터 안전

모든 계층이 읽기 전용 뷰입니다. 무엇을 조회하든 실제 테이블은 절대 변경되지 않습니다.

2

실시간 최신성

별도 동기화·배치 없이 질의 시점의 DB 상태를 그대로 반영합니다.

3

비개발자도 사용 가능

마법사·시각 편집기로 스키마에서 지식그래프를 자동 생성하고, 클릭만으로 검증 규칙을 만듭니다.

4

데이터 품질 자동 검증

"청구금액과 정산금액 차이가 기준 초과" 같은 규칙을 저장해두고 반복 검증 + 기간 비교 + What-if 시뮬레이션까지 지원합니다.

현재 상태 & 다음 단계

완료

Ontology / Mapping 자동 생성 (Bootstrap)

테이블 선택만으로 온톨로지·매핑을 자동 생성. 단일 PK 테이블 기준, 복잡한 스키마는 수동 편집기 지원.

완료

Pipeline — 조인 · 집계 · 파생 필드

여러 테이블을 결합·집계하고, 조건에 따라 등급을 분류하거나 값을 계산하는 파생 필드까지 지원.

완료

Rule — 검증 · 기간 비교 · What-if

같은 규칙으로 지금 검증, 지난달 대비 비교, 기준값을 바꿔보는 시뮬레이션까지 모두 실행 가능.

완료

SPARQL 조회 결과 그래프 시각화

조회 결과를 표 또는 노드-엣지 그래프로 전환, 관련 데이터를 N단계까지 자동 확장.

진행 예정

실행 엔진 상시 기동 연결

지식그래프를 실제 라이브 서비스로 띄우는 마지막 연결 고리.

진행 예정

검증 이력 대시보드 & 스케줄링

규칙 실행 결과를 주기적으로 자동 실행하고, 추세를 대시보드로 확인.

요약: 데이터 모델링·조회·검증까지 핵심 기능은 사용 가능한 수준으로 구현되었고, 남은 작업은 "상시 운영"을 위한 마감 작업(스케줄링, 이력 대시보드, 실행 엔진 상시화)입니다.
