AI-Native

SPARQL을 몰라도 됩니다 — 그냥 질문하세요

N2SPARQL 엔진이 자연어 질문을 정확한 SPARQL 질의로 자동 변환합니다. 온톨로지 구조를 이해하고 있는 질의이므로, 잘못된 필드나 존재하지 않는 관계를 참조하지 않습니다.

  • "이번 달 청구금액이 정산금액보다 10만원 이상 많은 고객은?" 같은 질문을 바로 실행 결과로 받습니다.
  • 생성된 SPARQL은 항상 함께 표시되어, 결과를 검증하고 필요하면 직접 수정할 수 있습니다.
  • 결과는 표 또는 그래프로 즉시 시각화되어, 연결된 데이터를 계속 따라가며 탐색할 수 있습니다.

How it works

4단계로 시작하세요

연결 선택

이미 등록된 데이터베이스 연결을 선택합니다.

자동 생성

테이블을 고르면 지식그래프 구조가 자동으로 만들어집니다.

자연어로 질의

궁금한 것을 그대로 물어보면 SPARQL로 변환되어 실행됩니다.

검증 규칙 저장

반복되는 점검은 규칙으로 저장해 자동으로 지킵니다.

FAQ

자주 묻는 질문

기존 데이터베이스를 옮겨야 하나요?

아니요. VKG는 원본 데이터베이스에 연결만 할 뿐, 데이터를 복제하거나 이동하지 않습니다.

복잡한 스키마도 지원하나요?

단일 키 테이블은 자동 생성되며, 복합키·자기참조 등 복잡한 구조는 시각 편집기로 직접 구성할 수 있습니다.

자연어 질의는 어떤 질문까지 가능한가요?

등록된 온톨로지의 클래스·속성·관계 범위 내 질문을 지원하며, 생성된 SPARQL이 항상 함께 표시되어 결과를 검증할 수 있습니다.

보안은 어떻게 관리되나요?

모든 질의는 조회 전용(SELECT)이며, 연결 권한은 기존 데이터베이스 계정 권한을 그대로 따릅니다.

지금 데이터를 의미로 연결해보세요

기존 데이터베이스 연결 정보만 있으면 몇 분 안에 시작할 수 있습니다.
