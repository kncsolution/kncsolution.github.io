A FEW THINGS TO KNOW
궁금한 점을
먼저 살펴보세요.
기존 데이터를 다른 곳으로 옮겨야 하나요?
Ontop의 가상 지식 그래프는 연결된 원본 DB에서 질의를 실행합니다. 의미 모델을 사용하기 위해 데이터를 별도 그래프 DB에 복제할 필요는 없습니다. 여러 DB를 함께 조회하려면 추가적인 통합 구성이 필요합니다.
AI가 업무 정의를 자동으로 결정하나요?
AI는 개념과 관계, 매핑의 초안을 제안합니다. 사용자가 검토하고 반영한 정의를 기준으로 조회하며, 모호한 조건은 확인하는 방식으로 설계했습니다.
로컬 실행은 무엇을 의미하나요?
언어 모델의 처리를 사용자 PC 또는 사내 서버에서 수행한다는 의미입니다. 원격 DB를 연결하면 해당 DB와 통신합니다. 홈페이지의 데모는 외부 AI나 데이터베이스에 연결하지 않는 샘플 시연입니다.
이 페이지에서 실제 제품을 사용할 수 있나요?
현재 페이지는 제품 설계를 소개하는 로컬 홈페이지입니다. 제품 화면과 조회 결과는 기능을 설명하기 위한 시연이며, 실제 통합 프로그램이나 설치 파일은 포함되어 있지 않습니다.
